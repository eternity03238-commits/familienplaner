# Freigegebene Original-Illustrationen (PNG-Master)

Hier gehören **ausschließlich die drei in ChatGPT freigegebenen Originaldateien** hinein, unverändert:

| Szene | Dateiname |
|---|---|
| Observatorium Abend | `futuristische_sternwarte_im_abendlicht.png` |
| Observatorium Nacht | `moderne_sternwarte_unter_dem_mond.png` |
| Vulkan-Forschungsstation | `dämmernde_vulkan_forschungsstation_mit_lavaglühen.png` |

**Hochladen über GitHub (kein ZIP):** github.com → Repository → Branch `integration/visual-world-v3` → dieser Ordner → *Add file → Upload files* → PNGs hineinziehen → *Commit changes*.
Auf dem iPhone in Safari „Desktop-Website anfordern“ aktivieren.

Danach erzeugt `npm run art:export` die 12 AVIF/WebP-Ausschnitte und `assets-manifest.json`; `npm run art:verify` prüft Herkunft (SHA-256), Formate, Maße und Budgets.
Keine generierten Ersatzbilder, keine Nachzeichnungen in diesem Ordner.
